# 物理モデル・ピアノ（Pianoteq 参照の自作実装）

`src/physmod/piano.py`。**サンプル不使用**でピアノ音を物理から合成する。
UVI Ravenscroft（暗号化サンプルライブラリ・ライセンス物）は学習・派生に使わず、
**Pianoteq が公開している物理モデルの考え方**を参照して独自実装した。

## Pianoteq（Modartt 公式）→ 本実装の対応

| Pianoteq の要素（公式マニュアル） | 本実装での扱い |
|---|---|
| 弦の剛性 → `f_n = (nc/2L)√(1+Bn²)` | `f_n = n·f0·√(1+B·n²)`、`inharmonicity(midi)` で B を音域変化 |
| ハンマー打弦位置（strike point） | `strike_pos=1/8`、コーム `|sin(nπp)|` で節を抑圧 |
| フェルト硬さ・ベロシティ→輝度 | `n_cut = 4+20·velocity` で高次倍音の到達範囲を制御（強打ほど明るい） |
| 複弦（unison）のうなり | わずかに離調した `n_strings=2` 本を加算 → ビート |
| 二段階減衰（direct + remanent） | 各倍音を `g·e^(-t/τ_fast)+(1-g)·e^(-t/τ_slow)` の2成分で |
| 高次ほど速い減衰 | `τ_n = τ_slow/(1+0.006n²)` |
| 響板（soundboard）の色付け | 低域共鳴を 2 個の `iirpeak`（105/215Hz）で軽く付与 |
| ダンパー（サステイン） | `sustain=False` でノートオフ後の減衰を加速 |
| 共鳴・デュプレックス | 未実装（次段。全弦共鳴＝サステインペダル時） |

手法選択は研究の推奨通り **modal/additive**。FDTD（OpenPiano 系）は安定性条件・
空間離散化の管理コストが高く「完成前に力尽きやすい」ため、要素を独立に積み上げられる
加算方式を採った。Pianoteq 本体の内部アルゴリズムは非公開のため、対応は
「公開用語からの対応づけ」であって内部再現ではない。

## 検証（examples/piano_demo.py, 実行済み）

**インハーモニシティの設計 vs 合成音からの回収**（`measure_inharmonicity`）:

| MIDI | f0 | B 設計 | B 回収 | 8倍音の上ずり |
|---:|---:|---:|---:|---:|
| 40 (A1) | 82.4 | 5.25e-5 | 9.2e-5 | +2.9 cent |
| 52 (E3) | 164.8 | 6.20e-5 | 7.6e-5 | +3.4 cent |
| 64 (E4) | 329.6 | 9.08e-5 | 1.35e-4 | +5.0 cent |
| 76 (E5) | 659.3 | 1.33e-4 | 1.31e-4 | +7.3 cent |
| 88 (E6) | 1318.5 | 1.95e-4 | 2.43e-4 | +10.7 cent |

- 中〜高音で設計値と回収値がよく一致。**8倍音の上ずりが高音ほど大きい**のは実ピアノの正しい挙動。
- 低音（MIDI40）の回収は複弦うなり＋密な倍音で推定器が振れやすく、やや高めに出る（測定側の限界。モデルは設計 B を正しく適用している）。
- ベロシティ→輝度、複弦うなり、二段階減衰、響板共鳴を確認。

## 既知の調整余地 / 次段

- **voicing（音色の明るさ配分）**は耳での調整パラメータ。`n_cut`・`k` の指数・響板ゲインで整える。
- **共鳴（sympathetic resonance）**とハーフペダルは未実装。サステインペダル時に全弦を弱く励振する層を足す。
- **ハンマー非線形**は raised-cosine 近似。厳密には Chaigne–Askenfelt 型の非線形接触を弦の運動と連立。
- この物理ピアノは、DDSP ハイブリッドの**クリーンな学習素材**（ライセンス問題なし）としても使える。
