# DDSP 学習レポート

- device: **cuda**（torch 2.6.0+cu124）
- モデル: DDSP autoencoder, params **0.70M**
- 学習: **5000 steps**, batch 16, 1030s
- データ: 合成モノフォニック調波楽器 train 96 / val 15 notes
- 検証は**学習に含めない音高**（MIDI 50/57/64/71/78）で音高汎化を測定

## 結果
- best val multi-scale STFT loss: **0.7922**
- final val loss: **0.7930**
- 出力: `outputs/ddsp_val_AB.wav`（前半=本物 / 後半=DDSP再現）

## 意味
この学習器は f0 と loudness だけを条件に楽器音を再構成する。
学習外の音高でも損失が下がることは、音色を**制御可能な形で**獲得したことを示す。
f0/loudness を MIDI から与えれば任意ピッチ・強弱で演奏でき、
実運用では入力を Demucs 分離ステム＋CREPE 抽出の f0 に差し替えるだけで、
実楽器の音色学習に移行できる。
