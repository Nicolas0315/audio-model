## 所見: 物理モデルと DDSP の補完関係（この実験の要点）

入力は自作の物理ピアノ（`src/physmod/piano.py`）から生成したモノフォニック独奏
（ライセンス問題ゼロの実素材）。DDSP はこれを f0/loudness から再構成するよう学習した。

- **val MSS 損失は 1.16 に収束**。合成「調波」楽器での 0.79（`ddsp_training_report.md`）より**高い**。
- 差の原因は明確: ピアノは剛性により倍音が**非整数（インハーモニック）** `f_n=n·f0·√(1+Bn²)`。
  一方 DDSP の harmonic oscillator は**整数倍音** `f_n=n·f0` を仮定する。
  よって DDSP は全体の音色は掴むが、倍音の上ずり（高音側で顕著）を平滑化してしまう。
- これは欠陥ではなく**役割分担の実証**: 非整数倍音・打弦・複弦うなりのような物理現象は
  **物理モデル**が native に扱い、DDSP は「録音から音色を素早く獲得し MIDI で弾けるようにする」
  層として使う。両者を組み合わせるのが本プロジェクトの設計（`docs/architecture.md`）。

## 再現手順

```bash
# 物理ピアノからモノフォニック独奏を生成（samples/piano_solo.wav, 16k mono, 30s）
python examples/make_piano_corpus.py
# その独奏でDDSPを再学習
python examples/retrain_from_stem.py samples/piano_solo.wav --steps 3000 --batch 8
```
